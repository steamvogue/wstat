# wstat banner

`wstat-banner.png` is the project README banner, generated with the built-in
`image_gen` tool on 2026-10-10. The final PNG retains its native
2172 × 724 resolution; GitHub scales it to fit the README.

The final mascot is a friendly goblin, revised from the initial penguin concept
at the owner's request using the same built-in tool.

## Initial generation prompt

Use case: logo-brand. Asset type: a polished wide GitHub README banner for the open-source Linux terminal tool wstat. Primary request: a Linuxy / sysadmin pixel-art project logo and banner. Make a wide landscape banner, about 1536 by 512 pixels (3:1). Subject: a charming compact original pixel penguin sysadmin, seated at a small terminal displaying an amber >_ prompt; pair this mascot with a large highly legible lowercase pixel wordmark wstat. Add a restrained cluster of green and amber traffic bars suggesting a live web-server monitor, not a detailed fake application screenshot. Style: authentic crisp 16-bit pixel art, consistent coarse square pixel grid, hard stepped contours, clean flat colors, no smoothing. Scene/background: deep charcoal almost black flat background, ample negative space, balanced horizontal composition suited to displaying at 960 pixels wide in a README. Colors: terminal amber, green, soft grey, black and white penguin, small warm accents. Text (verbatim): "wstat" and underneath in smaller but clearly readable pixel lettering "Live web traffic in your terminal". No other text. Constraints: looks good on GitHub dark and light pages due to its own dark background, tasteful restrained admin-tool aesthetic, intentional professional branding, no existing copied mascot drawing, no badges, no version number, no frames pretending to be browser UI, no photographs, no 3D, no gradients, no blur, no tiny illegible pseudo-code.

and the window title), client addresses and request paths have been replaced.

in this repository, and the hostname/address mapping is deliberately not stored.
