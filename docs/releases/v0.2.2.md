# wstat v0.2.2

URL paths, client addresses and agents now use brighter grey text across all
themes. Live requests add bot markers and compact agent identities while
keeping the URL visible.

## Readability and live request details

- Replace faint URL/client-agent text with a dedicated readable text colour
  in amber, ocean and mono themes.
- Show a leading **`b`** on live requests classified as bots, matching the
  Clients pane's marker.
- Show compact browser/bot identities such as `Chrome/124.0`,
  `Googlebot/2.1` and `curl/8.5.0` beside live URLs when space permits.
  Clients retain longer platform/agent text.
- Prioritize URL space: shorten or omit the agent before cutting a URL that
  otherwise fits. Narrow live rows omit time/client columns to retain the
  URL, status and byte count.
- Measure padding and truncation in terminal cells so wide Unicode paths
  do not push later columns out of the row.

## Validation

Full local Go tests, vet, lint and build passed. Regression tests cover
38–248-cell live rows, short/long/wide Unicode URLs, bot/human markers,
missing agents, complete-URL preservation, browser/bot summaries and all
three themes.

The compiled CLI passed an isolated `TERM=xterm-256color` PTY check:
URLs, Chrome/Googlebot identities and the bot marker were visible, URL text
used light-grey palette index 251, and no RGB sequences were emitted. The
process exited normally. Captured theme frames were also visually reviewed
with illustrative sample data.

See [readability evidence](../implementation/readability-review.md) and
[current usage](../../README.md). Successful CI race tests, the release workflow
and published artifact verification are recorded in the GitHub release notes.
