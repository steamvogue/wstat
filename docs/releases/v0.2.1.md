# wstat v0.2.1

Hosts freeze and stream pause now use distinct lowercase keys, with indicators
that name the affected panel and show how to resume it.

## Updated controls

- **`f`:** freeze/resume Hosts rows and values. Press again to catch up
  immediately. Ingestion and other panels continue updating.
- **`z`:** pause/resume stream auto-follow. Press again to jump to the latest
  visible request and resume following. The Hosts freeze state is independent.
- **`p`:** continues to filter the selected URL path. `z` had no existing binding.

When upgrading from v0.2.0, use `f` instead of `F` for Hosts and `z` instead of
`f` for stream pause. Uppercase `F` is no longer assigned. While entering a
search query, these letters remain search text.

## Indicators and help

Hosts show `[frozen] f resume`; the stream shows `[paused] z resume`. Header
chips identify the same independent states. This replaces the generic
`frozen` header chip, which described stream auto-follow even when Hosts were
also frozen. Compact bottom hints now include `f freeze` and `z pause`.

Generated release output is now ignored by Git so it does not mark build
metadata dirty. A reusable local verifier checks published archives and their
embedded source revision.

## Validation

Full local Go tests, vet and lint passed. Regression tests cover independent
toggles, immediate catch-up, both views and all focused panels, path-filter
preservation, search text and help visibility across terminal sizes.

An isolated compiled-CLI PTY check with `TERM=xterm-256color` exercised
`f, z, z, f`: a new host stayed hidden while Hosts were frozen, remained hidden
through both stream toggles, and appeared when Hosts resumed. The program
exited normally.

See the [follow-up evidence](../implementation/scrolling-review.md#freeze-indicator-follow-up-v021)
and [current keymap](../../README.md#keymap). Successful CI race tests and
published artifact verification are recorded in the GitHub release notes.
