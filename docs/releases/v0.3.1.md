# wstat v0.3.1

Startup now shows an animated loading line while configuration and sources are
loaded, and quitting leaves a fresh line for your shell prompt.

## Startup and exit

- Show a single-line ASCII spinner during interactive startup, including
  configuration loading and source detection.
- Stop the animation and clear its line before opening the dashboard or
  printing startup diagnostics, so progress never overwrites those messages.
- Keep redirected diagnostics, `TERM=dumb` and non-dashboard commands such as
  `--version` free of animation/control sequences.
- Print a newline after the dashboard returns, so `q` leaves the next shell
  prompt on a clean line.

## Validation

Full local Go tests, vet, lint and static builds passed. Regression tests check
changing animation frames on one line, cleanup before diagnostics, repeated
cleanup, redirected stderr and non-dashboard CLI output.

The compiled CLI passed an isolated `TERM=xterm-256color` PTY check using a
FIFO to delay configuration reading. Both successful startup and invalid
configuration produced changing spinner frames, then cleared progress before
the UI/error. Quitting with `q` left the next shell prompt on a fresh line;
exit codes were zero for normal quit and one for the config error.

CI race tests, the release workflow and downloaded artifact verification are
