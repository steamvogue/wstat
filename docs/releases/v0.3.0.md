# wstat v0.3.0

Freeze any focused pane with `f`, keep several panes stable for copying, and
resume them all with Shift+F. Other panes, ingestion and totals keep updating.

## Independent pane snapshots

- Hosts, Top URLs, Clients, Live Requests, PHP-FPM and Source Health each have
  their own freeze state. The stream shares its state between both views.
- `f` freezes or resumes the focused pane immediately. This replaces the
  previous binding that always toggled Hosts, regardless of focus.
- Shift+F unfreezes every pane, including panes in the hidden view. It preserves
  the separate `z` stream auto-follow pause and current filters.
- Frozen panes show `[frozen] f resume` and are named in the header. Bottom help
  includes `f freeze` and `F thaw all` in Dashboard and Services.
- Frozen snapshots retain rows, values and order while logs keep arriving.
  Scroll, search, zoom and resize within the retained data. Frozen requests
  remain available even after leaving the live recent buffer.
- Filter/sort changes and clearing filters keep panes frozen. Current settings
  apply on resume; frozen table labels/markers describe the captured settings.
- On stream resume, auto-follow selects the latest request. With auto-follow
  paused, selection stays on the inspected request if still available, or
  falls back to the oldest visible request if it has expired.
- PHP-FPM pool counters and source diagnostics stay stable in frozen panes;
  header alerts and source counts continue to reflect live data.

`z` pauses auto-follow while records continue updating; `f` on Live Requests
retains its data. Exit search entry before pressing these shortcuts, since
letters are query text while typing a search.

## Validation

Full local Go tests, vet, lint and the static build passed. Regression coverage
includes every pane's bindings, simultaneous freezes, individual/global resume,
stream rollover, retained selection, search/zoom/resize, filter-map isolation,
live FPM alerts, real source discovery, empty panes and Shift+F event forms.

An isolated compiled-CLI `TERM=xterm-256color` PTY check froze Hosts, URLs and
stream together while twenty requests were appended to a real access log.
Scrolling kept the stream stable, resuming URLs left other panes frozen, and
uppercase `F` resumed them all while preserving `z`. The process exited zero.
